About the repair and download limits

A fast remux reconstructs MP4 timing metadata and moves its index for compatibility. If the source contains unsupported video codecs, broken timestamps, or a requested smaller size, the video is converted to H.264 + AAC instead. Remuxing without re-encoding preserves video quality, but conversion does not.

This tool processes media on your own device. It needs the video host to allow browser downloads with CORS. If the server blocks CORS, download the file another way, then use "Fix local video" above. The browser cannot repair a completely missing/damaged media stream. Large files may exceed browser memory.

"Original" means highest-quality variant returned by TikWM, not a guaranteed untouched TikTok upload. 720p/480p are generated from that source when necessary, rather than claiming that TikTok provides separate versions.
